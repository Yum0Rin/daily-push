# daily-push 文档中心

本文档库面向**开发者 / 维护者**，讲清系统怎么运作、每块怎么改。新手快速上手请先看仓库根目录的 [README.md](../README.md)。

## 与根 README 的分工

| | 根 `README.md` | `docs/`（本目录） |
|---|---|---|
| 面向 | 使用者 / 首次接触 | 开发者 / 维护者 |
| 回答 | 这是什么、怎么跑起来、能用什么 | 为什么这么设计、内部怎么运作、怎么改 |
| 内容 | 简介、技术栈、目录、数据流、快速开始、能力与限制 | 架构细节、数据源契约、前端实现、配置参考、隐私处置、已知问题 |
| 详略 | 每个模块一句话概览 | 每个模块的内部设计与约定 |

原则：**README 只概览，docs 承载细节**。改代码时优先维护 `docs/` 下对应文件，不要在 README 里堆实现细节。

## 推荐阅读顺序

新开发者按 架构 → 数据源 → 前端 的顺序读；改 `config.json` 前先读 config-privacy；接手维护先看 status 了解已知问题与近况。
