# 当前状态与已知问题

> 更新日期：2026-09-22

## 可用能力 ✅

- 网易云日推（数量不限，含 top1 热评）；本地 `netease.mode=api`（Cookie+:3000 Node 代理），云端同用 `api`；`ncm-cli` 备用
- 网易云评论/收藏过滤：评论 > `netease.max_comments`（默认 10000）、收藏 > `netease.max_favorites`（默认 0=不限）的歌跳过并顺延下一首
- B站动态带视频封面（**窄屏 2 列 / 宽屏 3 列等高网格**）；网易云专辑封面（https）正常显示
- 公众号卡片带封面（比 B站更宽：B站 3 列 / 公众号 2 列；封面 2.35:1、标题固定两行）；历史公众号可从本地微信库补全
- 隐藏缓冲：各源多取 `reserve`（默认 3）条隐藏，被忽略/过滤后顺延补满
- 跨天去重：按历史已推 URL 过滤（`pushed_urls`），一条内容只推一次；cutoffs.json 仅作时间兜底
- B站 UP动态 —— 走「关注动态」接口，1 次请求拉最近视频，快且轻
- 公众号推文（标题 + 链接 + 作者 + 封面）—— 稳定，数量不限
- 本地**无常驻**：登录时一次性采集并推送（`tools/run_daily.py`，跑完退出）；Flask 网页**按需启停**（开始菜单「每日推送」打开，设置页「停止本地服务」关闭）；网易云代理**懒加载**（仅「检测网易云 / 手动推送 / 清理发布」期间，引用计数自动开关）；07:30 定时采集由云端 GitHub Actions 负责
- **跨平台**：同一份代码可在 Windows / Linux 跑本地部分；Linux 用 `tools/install_linux.py` 装 systemd 用户服务 + 应用菜单入口（详见 [linux.md](linux.md)）
- 失败通知：本地/云端统一发邮件，主题标明环节与来源（本地采集**连续失败 2 次**才发，防抖动误报）
- 失败重试：采集每 5 分钟、推送每 60 秒，网络恢复后自动补上
- Cookie 自动修复：回复报错邮件贴新 cookie，云端轮询更新 Secrets + 本地自愈写回 config.json
- 存储：按日合并（失败不覆盖当天）；`push_date` 固定北京时间（UTC+8）
- 本地设置页 `/settings`：可视化编辑屏蔽名单 / 平台登录态（Cookie 更新 + 验证）/ 采集参数；「手动推送」一键跑定时流程；「停止本地服务」按需关闭；仅本机、Host/Origin/CSRF 鉴权、密钥打码
- 配置分层：`settings.json`（非密钥策略，跟踪入库）与 `config.json`（密钥，gitignore），本地/云端同源
- 屏蔽词全量生效：保存后清理历史/今天 → 重发 Pages → 推送 `settings.json` 到 `code`
- 跨进程文件锁：采集/清理/推送/导出串行化（`publish_lock.py`）
- 设置页：运行状态（含「手动推送」「停止本地服务」）、配置备份/还原、安全响应头、ⓘ 悬停引导
- 单元测试 71 项（标准库 `unittest`，零新依赖）
